# Цветной граф в Obsidian

## Когда применять

Пользователь открыл vault в Obsidian и говорит, что граф нечитаемый: все узлы одного цвета, непонятно, где цель, где урок, где тема.

## Шаги

1. Открой Settings → Appearance (или Graph view → ⚙) → Color groups.
2. Добавь по одной группе на каждый тег из `AGENTS.md` §4: `tag:#цель`, `tag:#привычка`, `tag:#урок`, `tag:#навык`, `tag:#человек`, `tag:#проект`, `tag:#тема`.
3. Цвет — контрастный, разный для каждой группы; подпиши группы.
4. Скажи пользователю, что Obsidian красит только узлы, а не рёбра: тип связи читается по цвету концов.

## Грабли

- Плагины для раскраски рёбер не нужны и не ставятся — это визуальная настройка самого Obsidian, ноль токенов и ноль зависимостей.
- Группы не синхронизируются через git: при переносе vault на другую машину их надо задать заново.

## Проверка

Graph view → в графе видны минимум два разных цвета, и узел с тегом `#урок` отличается от `#цель`.
