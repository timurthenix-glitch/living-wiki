# Демо-vault

Иллюстративный пример того, как выглядит структура и наполнение живой вики после нескольких сессий: формат frontmatter, `[[wikilinks]]`, стрики привычек, статусы `факт`/`вывод`/`противоречие`, append-only `log.md`, Weekly-обзор.

Это не устанавливается и не подхватывается плагином автоматически — просто образец для наглядности. Свою реальную структуру агент создаёт по `AGENTS.md` / `skills/living-wiki/references/setup.md`.
