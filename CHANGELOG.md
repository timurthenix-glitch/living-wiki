# Changelog

В проекте принята единая финальная версия **v1**. Все улучшения вносятся непосредственно в неё без дробления на минорные подверсии (0.1, 0.2 и т.д.).

## Версия 1 (финальная) — 2026-10-04

Единая законченная система «Живая Вики» с полным автоматизмом и контуром саморазвития:

- **Полный автоматизм без ожидания команды:** агент самостоятельно выявляет уроки, цели, решения, привычки, ошибки и успехи из любого сообщения пользователя и фиксирует их в фоне. Запрещены пассивные вопросы «записать это?».
- **Краткая авто-сводка в конце каждого ответа:** при любой записи в `wiki/`, `self/` или `journal/` агент выводит строку `✓ зафиксировал: [...]`.
- **3-уровневая архитектура памяти (LOD 0/1/2):**
  - **LOD 0 (Атлас):** `python scripts/engine.py status` — ультра-компактный дашборд (~150 токенов) для быстрой ориентации без чтения всех файлов подряд.
  - **LOD 1 (Рабочий срез):** `self/Lessons-Learned.md` (до 150–200 строк самых актуальных уроков).
  - **LOD 2 (Исторический архив):** `self/Lessons/` для долгосрочного хранения без потери семантического поиска.
- **Единый контур максимальной эффективности (`scripts/engine.py`):**
  - Локальная семантическая память SQLite (`storage.py`, `text.py`) с порогом $\ge 0.88$ и умным fallback ($\ge 0.35$).
  - Action Fusion (`fuse`): авто-сжатие логов и фоновая синхронизация памяти при выполнении команд.
  - Evidence-Preserving Reducer (`reduce`): сжатие длинных логов с посимвольной верификацией цитат (zero hallucination).
  - ObservationPack (`pack` / `recall`): постраничная упаковка больших дампов и текстов.
- **Один источник правды и чистота корня:**
  - Запрет на параллельные хранилища памяти.
  - Запрет на хранение сырых файлов в корне — всё структурировано по `raw/`, `attachments/`, `wiki/`, `self/`, `journal/`.
- **Obsidian-совместимость:** связывание двусторонними `[[wikilinks]]`, граф знаний, теги и цветовые группы.
