# Changelog

`bootstrap_version` в `AGENTS.md` и `skills/living-wiki/SKILL.md` — маркер схемы правил, оба файла обновляются синхронно и **точно** совпадают. `version` в `.claude-plugin/plugin.json` — semver самого пакета: он обязан быть **не меньше** правила-маркера, иначе Claude Code не предложит обновление. `scripts/check-version-sync.sh` (в CI) проверяет оба правила, свежесть развёрнутой копии определяется `rules_hash` (`scripts/rules-hash.sh`).

## Package v1.1.1 — 2026-10-27

Память — один файл `MEMORY.md`, процедуры — `skills/`. Ни графа, ни базы данных.

- **Горячий слой `MEMORY.md`:** плоский список коротких декларативных фактов в пяти разделах (о пользователе, проект и стек, решения, грабли, открытые вопросы), лимит 6000 символов; дубликаты сливаются, противоречия заменяются.
- **Холодный слой `memory/<тема>.md`:** детали по областям (архитектура, контракты, схема БД, бизнес-правила), читаются только когда тема всплыла. Переполнение сначала вытесняет деталь в тему и оставляет указатель, и только потом сжимает; файлы тем не режутся.
- **Скилы:** `skills/<имя>/SKILL.md` с frontmatter `name`/`description`/`updated`; создаются при повторе процедуры, дописываются после использования, переписываются после двух провалов.
- **Аудит ответа:** четыре вопроса перед каждым содержательным ответом, запись сразу — не в конце сессии и не по слову «закончили».
- **Установка в проект:** два файла (`AGENTS.md` + `MEMORY.md`); папка `skills/` появляется с первым скилом.
- **`rules_hash`:** свежесть развёрнутой копии правил определяется sha256 слоя инструкций, а не номером версии.
- **Указатели:** восемь файлов для инструментов, которые не читают `AGENTS.md` сами, генерируются из `templates/rule-pointer.md`.

## Package v1.1.0 — 2026-10-27

Введение двухслойной памяти: `MEMORY.md` (горячий слой) + `memory/<тема>.md` (холодный слой). Правило переполнения 6000 символов: сначала вытеснение в тему, затем слияние дубликатов, и только потом сжатие формулировок.

## Package v1.0.0 — 2026-10-27

Единая финальная версия `v1`, без подверсий и минорных номеров. Ядро правил сокращено, повторяемые процедуры вынесены в скилы, свежесть копии определяется `rules_hash`.
