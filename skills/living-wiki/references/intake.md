# Приём данных со стороны (опционально)

Не обязательно для работы системы — агент может сам искать и создавать вики-страницы по запросу «сделай вики про X», тогда `raw/` вообще не участвует. `raw/` нужен именно тогда, когда пользователь сам хочет что-то докинуть вручную.

Если пользователь пользуется Obsidian как фронтендом, предложи один раз настроить:

1. **Obsidian Web Clipper** (расширение Chrome, obsidian.md/clipper) — превращает веб-страницу в markdown-файл. В настройках клиппера (Options → шаблон по умолчанию → Note location) укажи путь на папку `raw/`, чтобы всё, что клипается, само попадало в приёмную.
2. Плагин Obsidian **Local Images Plus** (Settings → Community plugins → Browse → найти, установить, включить) — без него клиппер подтягивает только ссылки на картинки, а не сами изображения.
3. Нативные **Color Groups** графа (Settings → Graph view → Color groups): одна группа-запрос `tag:#<тег>` на каждый тег из раздела 5 `AGENTS.md` (`цель`, `привычка`, `урок`, `навык`, `человек`, `проект`, `тема`). Obsidian не умеет красить сами рёбра — только узлы, — поэтому тип связи между страницами читается по цвету её концов — никакого стороннего плагина и никакого лишнего токена на это не требуется.
4. **Папка вложений** (Settings → Files & links → Default location for new attachments): выбери «In the folder specified below» и укажи `attachments`. При вставке скриншотов из буфера (Ctrl+V) Obsidian сам сохранит их в `attachments/`, не засоряя корень хранилища.

## Вложения и скриншоты проблем (`attachments/`)

Когда пользователь сталкивается с багом, ошибкой в консоли, проблемой верстки или проектирует архитектуру со схемами, к урокам или страницам вики часто прикрепляются графические материалы.

1. **Сохранение:** файл помещается в `attachments/<YYYY-MM-DD>-<slug>.<ext>` и встраивается через `![[attachments/<имя>]]`.
2. **Обязательное текстовое резюме (двойной контур):** скриншот **всегда** сопровождается 1–3 строками текста (суть проблемы, причина, решение). Человек видит наглядный скриншот в Obsidian, а агент мгновенно находит и понимает урок через текстовый поиск без расхода токенов на передачу картинок.
3. **Приватность личных скриншотов:** личные изображения не должны попадать в публичный git-репозиторий. Если хранилище версионируется в Git, добавь в корень хранилища `.gitignore`:
   ```gitignore
   attachments/*
   !attachments/.gitkeep
   *.png
   *.jpg
   *.jpeg
   *.gif
   *.webp
   *.svg
   ```

Если сверх этого захочется автоматизировать приём через хук/скрипт конкретного агента — можно, но это дополнение, а не замена. Такой скрипт обязан явно падать с ошибкой в `log.md`, если что-то пошло не так — тихое поглощение ошибки запрещено: молчаливая потеря данных хуже отсутствия автоматизации, потому что создаёт иллюзию, что всё работает.
