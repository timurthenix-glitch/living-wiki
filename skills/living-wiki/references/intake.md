# Приём данных со стороны (опционально)

Не обязательно для работы системы — агент может сам искать и создавать вики-страницы по запросу «сделай вики про X», тогда `raw/` вообще не участвует. `raw/` нужен именно тогда, когда пользователь сам хочет что-то докинуть вручную.

Если пользователь пользуется Obsidian как фронтендом, предложи один раз настроить:

1. **Obsidian Web Clipper** (расширение Chrome, obsidian.md/clipper) — превращает веб-страницу в markdown-файл. В настройках клиппера (Options → шаблон по умолчанию → Note location) укажи путь на папку `raw/`, чтобы всё, что клипается, само попадало в приёмную.
2. Плагин Obsidian **Local Images Plus** (Settings → Community plugins → Browse → найти, установить, включить) — без него клиппер подтягивает только ссылки на картинки, а не сами изображения.

Если сверх этого захочется автоматизировать приём через хук/скрипт конкретного агента — можно, но это дополнение, а не замена. Такой скрипт обязан явно падать с ошибкой в `log.md`, если что-то пошло не так — тихое поглощение ошибки запрещено: молчаливая потеря данных хуже отсутствия автоматизации, потому что создаёт иллюзию, что всё работает.
