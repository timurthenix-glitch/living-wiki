# Несколько агентов/инструментов в одном проекте

`AGENTS.md` в корне проекта — единственный полный источник правил. Не копируй его целиком в файлы каждого инструмента — вместо этого создай для каждого агента короткий файл-указатель того формата, который он ожидает (например `CLAUDE.md`, `.cursor/rules/...`, `.windsurf/rules/...`), содержащий одну-две строки: «Правила и память этого проекта — в `AGENTS.md` в корне, прочитай его перед началом работы».

Полный текст правил должен существовать в одном месте — иначе при следующей правке кто-то поправит одну копию, забудет про остальные, и они разойдутся молча.

Не полагайся на хук, автозапуск или прочую инфраструктуру, специфичную для одного инструмента, как на единственный способ что-то зафиксировать: то, что работает в одном агенте, может не существовать в другом. Постоянный цикл (`AGENTS.md`/`SKILL.md`, раздел 4) сформулирован так, чтобы сработать в любом агенте без всякой инфраструктуры — это и есть страховка.
