# Движок памяти (`scripts/engine.py`, `storage.py`, `text.py`)

Один интерфейс для любого агента: семантический кэш «вопрос → ответ» в SQLite (`.cache/memory.db`, в git не попадает) плюс приёмы SoL-Pi. Сторонних библиотек не нужно. Скриптов нет — работай вручную по тем же правилам.

## Ответ из памяти

```bash
python scripts/engine.py match "<вопрос>"
```

- Схожесть $\\ge 0.88$ — точный ответ, без обращения к LLM.
- Ниже порога — гибридный fallback ($\\ge 0.35$): топ-3 статьи с бонусом за совпадение ключевых слов в теле ответа. Это подсказка, а не готовый ответ.

## Сохранение решений

```bash
python scripts/engine.py store "<проблема>" "<решение>" --tags "теги"
```

Сохраняй проверенное: конфиг, который заработал, обход бага, найденную причину. Не сохраняй догадки — кэш читают как факт.

## Синхронизация

```bash
python scripts/engine.py sync
```

Индексирует `self/Lessons-Learned.md`, архив `self/Lessons/*.md` и `wiki/**/*.md`. Знание не теряется при архивации уроков — поэтому LOD 1 → LOD 2 безопасен.

## Атлас хранилища (LOD 0)

```bash
python scripts/engine.py status
```

Компактный дашборд (~150 токенов). **Строгий гардрайл:** на абстрактные запросы («чекни хранилище», «что в базе», «покажи статус») запрещено открывать и сканировать файлы подряд — это десятки тысяч токенов. Запусти `status`, верни карту и уточни фокус, прежде чем открывать конкретный файл.

## Action Fusion

```bash
python scripts/engine.py fuse "python scripts/test_memory.py"
```

Выполняет команду, сжимает вывод при превышении лимита и синхронизирует память после прогона.

## Evidence-Preserving Reducer

```bash
python scripts/engine.py reduce <путь_к_логу>
```

Сжимает длинный лог ошибок в квитанцию с посимвольной проверкой цитат. Сырой лог остаётся в `.cache/logs/`, в контекст и `journal/` попадает только проверенная выжимка.

## ObservationPack

```bash
python scripts/engine.py pack <файл>
python scripts/engine.py recall <obs_хэндл> --start 1 --lines 50
```

Объёмный входящий текст или дамп превращается в лёгкий дескриптор и читается страницами — вместо того чтобы заливать его в контекст целиком.

## Прочее

`python scripts/engine.py clean` — ротация логов. Общая семантическая память между разными агентами в одном проекте — `references/multi-agent.md`.
